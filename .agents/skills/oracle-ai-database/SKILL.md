# 🏛️ Oracle AI Database (23ai) & Select AI Architecture

Oracle AI Database (23ai) implements the strategic paradigm: **"Bringing AI capabilities natively into the database"** — moving AI logic, vector search, and agent execution directly to the data layer rather than exfiltrating enterprise data to external services.

## 1. Native VECTOR Data Type & Storage

Oracle 23ai introduces `VECTOR` as a first-class SQL data type.

### Table Schema Definition
```sql
CREATE TABLE enterprise_knowledge_base (
    doc_id        NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title         VARCHAR2(255) NOT NULL,
    chunk_id      NUMBER NOT NULL,
    chunk_text    CLOB NOT NULL,
    embedding     VECTOR(1536, FLOAT32), -- Supports FLOAT32, FLOAT64, INT8, BINARY
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 2. In-Database Vector Processing Pipeline

Oracle AI Database provides native PL/SQL pipeline utilities for text extraction, chunking, and embedding generation:

$$\text{Raw Document} \xrightarrow{\text{UTL\_TO\_TEXT}} \text{Plain Text} \xrightarrow{\text{UTL\_TO\_CHUNKS}} \text{Text Chunks} \xrightarrow{\text{UTL\_TO\_EMBEDDINGS}} \text{VECTOR}$$

```sql
-- Example PL/SQL Pipeline Transformation
DECLARE
    v_doc_blob    BLOB;
    v_text_clob   CLOB;
    v_chunks      VECTOR_CHUNKS;
    v_embedding   VECTOR;
BEGIN
    -- 1. Extract plain text from PDF/DOCX
    v_text_clob := DBMS_VECTOR_CHAIN.UTL_TO_TEXT(v_doc_blob);

    -- 2. Split text into semantic chunks
    v_chunks := DBMS_VECTOR_CHAIN.UTL_TO_CHUNKS(
        v_text_clob,
        JSON_OBJECT('by' VALUE 'words', 'max' VALUE '100', 'overlap' VALUE '10')
    );

    -- 3. Generate embedding using in-database ONNX model or OCI GenAI REST provider
    v_embedding := DBMS_VECTOR_CHAIN.UTL_TO_EMBEDDINGS(
        v_chunks(1),
        JSON_OBJECT('provider' VALUE 'oci', 'model' VALUE 'cohere.embed-english-v3.0')
    );
END;
/
```

## 3. Vector Search & Similarity Querying

Use `VECTOR_DISTANCE()` to perform semantic similarity searches.

```sql
-- Query nearest semantic matches using Cosine or Euclidean distance
SELECT doc_id, chunk_text, 
       VECTOR_DISTANCE(embedding, :query_vector, COSINE) AS distance
FROM enterprise_knowledge_base
ORDER BY distance ASC
FETCH FIRST 5 ROWS ONLY;
```

### Hybrid Vector Index
Combines vector (semantic) search with full-text keyword indexing:
```sql
CREATE HYBRID VECTOR INDEX idx_knowledge_hybrid 
ON enterprise_knowledge_base(chunk_text, embedding);
```

## 4. Select AI Agent Framework

Select AI Agent translates natural language inputs directly into verified SQL queries and RAG execution loops.

### Select AI Agent Execution Loop
Every Select AI Agent performs 4 mandatory steps:
1. **Plan:** Deconstruct natural language request into relational schema intent.
2. **Use Tools:** Execute metadata lookups, vector searches, and SQL queries.
3. **Summarize:** Synthesize SQL query results into natural language answers.
4. **Terminate:** Return response and clean up execution context.

```sql
-- Configuring Select AI Profile for Autonomous Execution
BEGIN
    DBMS_CLOUD_AI.CREATE_PROFILE(
        profile_name => 'ENTERPRISE_SELECT_AI_PROFILE',
        attributes   => JSON_OBJECT(
            'provider'       VALUE 'oci',
            'credential_name' VALUE 'OCI_CRED_INSTANCE',
            'object_list'     VALUE '[{"owner": "HR", "name": "EMPLOYEES"}, {"owner": "FIN", "name": "REVENUE"}]',
            'model'           VALUE 'cohere.command-r-plus'
        )
    );
END;
/

-- Invoking Select AI directly in SQL
SELECT AI generate natural language report of top 5 revenue departments for 2026;
```

## 5. Autonomous Database Native MCP Server

Instead of running an external Node.js/Python MCP proxy, Oracle Autonomous Database provides an **in-database MCP Server**:

* **Security Advantage:** Runs inside the database boundary, directly inheriting Virtual Private Database (VPD) and Role-Based Access Control (RBAC) security rules.
* **Operational Advantage:** Eliminates external server maintenance, network latency, and credential exposure.
